# 정금종의 동행라디오 · 프로그램 편성 설계안

경기도장애인체육회 기반, AI 정서 커뮤니케이션 플랫폼
**정금종의 동행라디오**의 프로그램 편성 설계안입니다.

> 짜인 시간표는 없습니다. **여러분의 말이 방송이 됩니다.**

## 공식 기반 — paraSports Gyeonggi

경기도장애인체육회의 슬로건 **"스포츠를 통한 교류와 도전"** 위에서 자랍니다.

- **도전 → 사연** / **교류 → 관계** / **그 마음 → 정서**
- **31개 시군지회** — 우리 동네 방송국(I 채널)의 거점
- **39개 가맹단체 종목** — 선수 서사(A·D 채널)의 원천
- **4대 공식 대회** — 대회가 열릴 때 특별 방송이 켜짐

## 우리가 다루는 것 — 단 세 가지

일자리·교육·복지 정보 같은 '뻔한 방송'은 다루지 않습니다.
오직 아무도 깊이 다루지 못한 **사람의 마음**에 집중합니다.

- **사연** — 살아온 이야기를 방송과 책으로 남깁니다.
- **관계** — 멈춰 있던 가족·이웃 사이를 다시 잇습니다.
- **정서** — 외롭고 힘든 마음을 가만히 들어주고 위로합니다.

## 7개 채널

- 사연 — A 경기도 장애인체육 레전드 · D 내 인생 이야기
- 관계 — C 가족의 목소리 · B 함께 걷는 동행(어울림) · I 우리 동네 방송국(31개 시군)
- 정서 — F 오늘의 위로 · E 동행 마음 상담

## 4대 공식 대회 (이벤트 방송)

경기도장애인체육대회 · 경기도장애인생활체육대회 · 경기도어울림체육대회 · 북부장애인체육대회.
각 대회의 한 회차가 참가자의 **자서전 한 챕터**로 남습니다.

## 배포 방법 (GitHub Pages)

1. 이 저장소에 `index.html`을 그대로 올립니다.
2. `Settings → Pages → Branch: main / root` 선택 후 저장.
3. 잠시 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 공개됩니다.

별도 빌드 과정 없이 단일 HTML 파일로 동작합니다.
